Chapter 1 · origin story
From Enigma to LLMs
80 years of machines learning to think — and why it finally matters for your daily dev workflow
1940sEnigma + Bombe — the first AI problem

Turing's Bombe at Bletchley Park. Not intelligence — but the conceptual seed: a machine processing symbols to extract meaning humans can't see in reasonable time. The adversarial "prompt" was a known plaintext crib.

Every prompt you write today is a crib. You're giving the machine a known-good handle to orient from.

1950Turing Test — can machines mimic?

The imitation game. The benchmark isn't intelligence — it's convincing mimicry. Every hallucination is a model optimising for mimicry over truth.

LLMs are still fundamentally imitation machines — extraordinarily refined ones. Don't forget it.

1966ELIZA — the first dopamine loop

Weizenbaum's ELIZA. Pattern matching + scripted reflection. Zero understanding. Infinite perceived empathy. The ELIZA effect: humans anthropomorphise even dumb pattern-matchers.

The dopamine loop was discovered in 1966. You're not immune. Neither are your teammates.

1980–90sExpert systems — the first AI winter

Billions spent encoding IF [symptom] THEN [diagnosis]. Brittle. No generalisation. Collapsed.

Hand-crafted rules don't scale. Statistical learning on massive data wins. Every time.

1997Deep Blue — superhuman narrow intelligence

IBM beats Kasparov. Not general AI — superhuman narrow intelligence.

Copilot autocomplete is Deep Blue for code tokens.

2012AlexNet — GPUs unlock deep learning

Krizhevsky et al. crush ImageNet. GPUs + big data + backprop = the modern stack.

Hardware unlocks capability. Same pattern as local LLMs on a laptop.

2017Attention is all you need

Self-attention replaces recurrence. Every major model today is a Transformer variant.

This generation's Enigma moment.

2018–20GPT-1 → GPT-3 — scale laws

Bigger model + more data = better, predictably. In-context learning emerges. The prompt becomes the programming interface.

2022ChatGPT + RLHF

100M users in 60 days. RLHF makes the model useful and conversational. The work dopamine loop is born.

2023–26Cambrian explosion

By mid-2026 the field is fragmented on purpose: Claude (safety + long context), Gemini (mass context + search), GPT (speed + vision), Grok (live X), Llama / Qwen (open weights), DeepSeek (cheap reasoning). Pick by failure mode, not brand.

Version tags rot every quarter. Roles stay stable.

Then
Mimicry machines
ELIZA to GPT-2: statistically plausible text. No planning, no tool use, no memory. Impressive demos, brittle in production.
Now (2026)
Reasoning + action
Claude Code, Cursor, Copilot Workspace: reads files, writes code, runs tests, pushes branches. Chat toy → engineering collaborator.
The wave you're riding
Not "AI is helpful". "AI can do 60% of the mechanical work if you direct it precisely". Senior job: know what to build, review output, catch failure modes, prompt with enough context that the machine doesn't invent requirements.

10 anti-patterns
  • 01"Write me the whole feature" with zero context. Stack, constraints, goal. One ask at a time.
  • 02Hopping 3 AIs for the same problem. Pick one, give full context, switch only when genuinely wrong.
  • 03Accepting first output unread. AI code has bugs. You review. Always.
  • 04Pasting company secrets into DeepSeek or free-tier tools.
  • 05Vague refactor: "make it better". Name the axis: perf, readability, DRY, bundle.
  • 06Using autocomplete for architecture. It predicts tokens, not systems.
  • 07"It doesn't work" is zero signal. Paste error + what changed + what you tried.
  • 08AI code + AI tests = no real coverage. Generate tests first, or alongside.
  • 09Treating output as final. It's a draft. Ship what you understand.
  • 10Long chat with accumulated wrong context. Start fresh when assumptions rot.
